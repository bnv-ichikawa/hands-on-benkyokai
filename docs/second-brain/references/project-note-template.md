# プロジェクトノートの型

期限のある社内プロジェクト(全社イベント、部門横断の案件対応など)を `second-brain/projects/` に記録するときの型です。[TECHNIUM Global Conference 2026](../../../second-brain/projects/technium-global-conference-2026.md) のノートから抽出しています。実物を見ながら読むと分かりやすいです。

Notion・Google Drive・Slack が正本を持つ情報(企業マスタ、契約書、進行中のやり取りなど)は、全文を複製せず、要点と参照リンクだけを残します。

## frontmatter

```md
---
tags:
  - <プロジェクトに関するタグ>
freshness: current
source_notes:
  - Notion「<正本ページ名>」 <URL>
  - 公式サイトなど、他に正本がある場合はそれも
---
```

## 本文の構成

```md
# <プロジェクト名>

<プロジェクトの目的を1〜2文で>

## 概要

| 項目 | 内容 |
| --- | --- |
| 会期・期間 | |
| 規模・対象 | |
| 主催・担当部門 | |

社内の担当は<部門名>([組織と部門](../../../second-brain/resources/組織と部門.md))。

## 進行体制

準備は Slack のチャンネル単位で分かれている。

| チャンネル | 担当範囲 |
| --- | --- |
| `#prj-<...>` | |

チャンネル名は [Slack チャンネル運用](../../../second-brain/resources/slack-チャンネル運用.md) の `prj-` に従う。

## 完了条件

<いつ・何をもって完了とするか。完了後は `archives/` へ移す旨も書く>

## 未確認事項

<まだ決まっていない・確認できていないこと>
```

## 使うときの注意

- 見出しはプロジェクトの実態に合わせて増減してよい。この型は最低限の骨格
- 「進行体制」のチャンネル一覧は、増えたら都度追記する。Slack 側の正本(チャンネル一覧そのもの)は持たない
- 完了条件を満たしたら、[`archives/`](../../../second-brain/archives/README.md) へ移す
