## 🌍 AIによって「人に求められる仕事」が変わっている

生成AIとAIエージェントの進歩によって、調査、文章作成、コーディング、分析、テストなど、これまで人が直接行ってきた「実行」の一部をAIが担える範囲が広がっています。

Microsoft の 2026 Work Trend Index は、AIとエージェントが実行を担うほど、人には **judgment（判断）、clarity of intent（意図の明確化）、work design（仕事そのものの設計）** がより重要になると整理しています。[[1]](https://www.microsoft.com/en-us/worklab/work-trend-index/agents-human-agency-and-the-opportunity-for-every-organization)

World Economic Forum の Future of Jobs Report 2025 では、AI and big data が2030年に向けて最も成長するスキル群に挙げられる一方、Analytical thinking は現在も重要なコアスキルとされています。[[2]](https://www.weforum.org/publications/the-future-of-jobs-report-2025/digest/)

ILO は、生成AIにさらされる仕事の多くは、人による入力が引き続き必要なため、仕事そのものが不要になるよりも、仕事の内容が変化する可能性が高いとしています。[[3]](https://www.ilo.org/publications/generative-ai-and-jobs-2025-update) OECD も、AI導入に伴い、AIそのものの知識だけでなく、データを利用・分析・解釈する能力などの重要性が高まると整理しています。[[4]](https://www.oecd.org/en/publications/ai-and-skills_f843b352-en/full-report.html)

Anthropic の Claude 実利用データでは、Claude の利用歴が長いユーザーほど、指示して任せる一方向の使い方より、出力を反復的に改善しながら進める傾向が報告されています。[[5]](https://www.anthropic.com/research/economic-index-march-2026-report)

こうした変化を踏まえ、BNVでは、人の価値を **AIより速く作業すること** には置きません。

**何を解くべきかを定め、仮説を立て、AIを使って高速に検証し、結果を評価し、意思決定し、最後まで責任を持つこと。**

これまで以上に、そこへ人の時間と専門性を使います。

## 🚀 BNVが目指す姿

私たちは、**2030年までに、アジアNo.1のAIネイティブで効率的なVC**を目指します。

AIネイティブとは、単にAIツールを導入することでも、既存業務をAIで少し速くすることでもありません。

**AIと人の現在の能力を前提に、仕事そのものを設計し直し続ける組織**であることを意味します。

「今の作業をどう自動化するか」だけでなく、「そもそもこの作業は必要か」「AIと人のどちらが担うべきか」「ゼロから業務を設計するならどうするか」を問い直します。

目指すのは、**受け身の実行者から、AIを使って仮説検証しながら課題を設定し、成果まで導ける人への転換**です。

## 🧭 共通原則

### AIには実行を任せても、判断と責任は任せない

AIは標準的な仕事の手段として積極的に利用します。

ただし、AIの出力は完成品ではなく、初稿・仮説・候補・実行結果です。成果物については、本人が内容を理解し、必要な検証を行い、**自分の判断として説明できる状態**にします。

AIを使うこと自体に価値があるのでも、AIを使わないことに価値があるのでもありません。

**AIを使ったうえで、人として何を判断し、どのような価値を付加したか**を重視します。
