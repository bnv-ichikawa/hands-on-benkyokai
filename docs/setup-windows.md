# Windows PC の準備

このリポジトリの標準のスライド作成は、公式スライドマスタに載せ替えやすい構成と本文を作る方式です。

## 必要なもの

**必要なソフトウェアは [何をするのに何が必要か](requirements.md) が正本です。** このページで確認するのは **Microsoft PowerPoint** です。

PowerPoint が入っていない PC では、`.pptx` の仕上げや確認は別の環境で行います。

## 事前確認

勉強会の前に、次を確認します。

1. PowerPoint を開ける
2. 公式スライドマスタ、または既存の `.pptx` を開ける

このリポジトリ内でスクリプトを実行して見本を書き出す確認は不要です。

## うまくいかないとき

### PowerPoint が見つからない

PowerPoint がインストールされていない可能性があります。Microsoft 365 または社内配布の Office が使える PC で実行してください。

### ファイルが見つからない

ターミナルの場所がリポジトリのルートになっているか確認します。

```powershell
cd "C:\Users\自分の名前\Desktop\ハンズオン勉強会"
```

パスに日本語や空白が入っていても、前後をダブルクォート `"` で囲めば大丈夫です。

### 文字やレイアウトが崩れる

PowerPoint で開いて、タイトルや表が重なっていないか確認します。崩れている場合は、`outputs/<名前>.json` の文字数を減らすか、PowerPoint 側で仕上げます。

## 当日の進め方

手でコマンドを覚える必要はありません。AI に「スライドを作りたい」と伝えれば、`make-my-slides` skill が内容を聞き取り、スライド用の構成と本文を作ります。
