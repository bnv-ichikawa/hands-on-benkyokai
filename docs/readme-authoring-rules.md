# README の書き方

このファイルは、このリポジトリ内の `README.md` に何を書くか、どこまで書くかを定める固定ルールです。

README は、そのディレクトリに入ってきた人の案内板として扱います。**初めて読む人が、その場所の目的・構成・基本的な使い方を短時間で把握できること**を優先します。

## 基本原則

### 1. README はそのディレクトリ自身を説明する

README には、そのディレクトリが何を担当する場所なのか、その配下がどう分かれているか、その階層に共通する使い方やルールを書きます。

**子ディレクトリの詳細な手順・理由・現在の状態を、親 README に再掲しません。** 必要な場合は子ディレクトリの README へリンクします。

### 2. 親 README は子ディレクトリの目的・責務までを書く

親 README で子ディレクトリについて書くのは、次の範囲までです。

- 何を置く場所か
- 何を担当するか
- どのような単位で分かれているか

子ディレクトリ固有の詳しい使い方、手順、理由、現在の状態、未決事項は、その子ディレクトリ側を正本にします。

### 3. 現在の状態も正本を1か所にする

現在の状態は、**その情報を所有する最も近い README にだけ**書きます。

たとえば「このスクリプトはまだ無い」「この値は未確定」を、親 README にも子 README にも書くことはしません。状態が変わったときに直す場所が増えないようにします。

決まりについては [CONSTITUTION.md の原則6](../CONSTITUTION.md#6-1つの決まりの正本は1つのファイルに置く) が定めています。**現在の状態にも同じ扱いを適用します。**

### 4. リンクは必要な文脈に置く

**関連ドキュメントを末尾に一覧化することを目的にしません。**

読者がその情報を必要とする箇所で、正本へリンクします。**同じリンクを本文と末尾の一覧の両方に置きません。**

### 5. 時点依存の情報を上位へ伝播させない

子ディレクトリの状態が変わるたびに親 README まで直す構造を避けます。

親 README に書くのは、長く変わりにくい目的・責務・構造・共通ルールを中心にします。

## README に書くもの

必要なものだけを選んで書きます。**すべての見出しを必須にはしません。**

| 内容 | 書くこと |
| --- | --- |
| 概要 | そのディレクトリが何をする場所か |
| ディレクトリ構成 | 配下の主要なディレクトリと、それぞれの役割 |
| 基本的な使い方 | その階層全体に共通する作業の流れ |
| 共通ルール | その README 自身が正本となる、その階層固有のルール |
| 現在の状態 | そのディレクトリ自身が所有する時点依存の情報 |

## README に書かないもの

| 内容 | 置き場所 |
| --- | --- |
| 子ディレクトリ固有の現在の状態 | 子ディレクトリの README |
| 子ディレクトリ固有の詳しい手順 | 子ディレクトリの README |
| すでに正本がある決まりの再掲 | 正本へのリンクだけにする |
| 本文ですでにリンクした資料の重複一覧 | 作らない |
| 調査ログ、一時的な確認結果 | README には置かない |

## 構成のツリーを書くとき

ディレクトリ構成は、**配下の役割を一言ずつ添えたツリー**で示します。一言は役割のラベルであって、決まりの説明ではありません。

```text
<directory>/
├── <child-a>/    <役割を一言で>
├── <child-b>/    <役割を一言で>
└── <child-c>/    <役割を一言で>
```

**ツリーに内部構造を全部展開しません。** 読む人が知りたいのは「何があるか」で、各所の内訳はその場所の README が持ちます。

## 現在の状態を書くとき

`現在の状態` は必要な場合だけ設けます。

書いてよいのは、**そのディレクトリ自身が所有する状態**です。配下の状態を集めたダッシュボードにはしません。

**事実として確認できるものだけを書きます。** 未確認の内容を推測で埋めません。

## 判断に迷ったとき

README に書くか迷った場合は、次の順で判断します。

1. その情報は、このディレクトリ自身の目的・構造・共通ルールか
2. 子ディレクトリ固有の情報なら、子側を正本にできないか
3. 時点依存の状態なら、その状態を所有する最も近い README にだけ置けないか
4. すでに正本があるなら、説明を複製せずリンクだけにできないか
