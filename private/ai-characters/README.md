# AIキャラクターの保管場所

このフォルダには、AIに与える人格（キャラクター）の定義ファイルが入っています。AIはここを読み書きできます。

親フォルダの [`private/`](../README.md) は、個人的な情報の置き場です。このフォルダはその用途のひとつで、自分のプロフィールや役割は [`../my-profile/`](../my-profile/README.md) に置きます。**Git での扱いは [`../README.md`](../README.md) が正本です。**

ただし、**いま人格として効いているのは `AGENTS.md` の内容だけ**です。ここに置いただけでは切り替わりません。

## 🚀 キャラクターを切り替える

1. このフォルダの中から、使いたいキャラクターの `.md` ファイルを開く
2. **中身を全部コピーする**（Ctrl+A → Ctrl+C）
3. リポジトリのルートにある `AGENTS.md` を開く
4. `AGENTS.md` の**中身をすべて消して**、コピーした中身を貼り付ける（Ctrl+A → Ctrl+V）
5. **`{このレポジトリの全体パス}` を自分のPCの実際のパスに置き換える。** プレースホルダーのままでは画像が表示されません
6. 保存する

`AGENTS.md` はキャラクター定義そのものです。差し替えるときは全体を置き換えます。

切り替えたら、**Codexで新しいスレッドを開始してください。**いま開いている会話には反映されません。

## キャラクターを追加する

AIに「新しいキャラクターを作りたい」と伝えると、質問しながらこのフォルダに下書きを作ります。

そのまま使うなら、下書きの中身を上と同じ手順で `AGENTS.md` に貼り付けてください。

書き方の決まりは [`.agents/skills/create-character/SKILL.md`](../../.agents/skills/create-character/SKILL.md) の「文章のルール」にあります。手で書くときもこれに合わせてください。

## 📏 注意

- 見出しは `##` から始めます。`#` の大見出しを使うと、貼り付けたときに `AGENTS.md` の階層が崩れます
- 作業の進め方や情報の扱いは `.agents/skills/` の各 Skill が持っています。キャラクターファイルには書きません
- 画像のパスの扱いは [CONSTITUTION.md](../../CONSTITUTION.md) の「5. 特定のPCでしか動かない状態を作らない」にあります
- **このフォルダのキャラクター定義は、テンプレートとして Git 管理されています。** 扱いは [`../README.md`](../README.md) にあります
