# TECHNIUM Global Conference 2026

ディープテックに特化した完全招待制の国際カンファレンス。創業前後の技術シーズに焦点を当て、産官学の多様なプレイヤーを有機的につなぐことを目的とする。

## 開催概要

| 項目 | 内容 |
| --- | --- |
| 会期 | 2026年9月2日（水）〜9月3日（木） |
| 会場 | セルリアンタワー東急ホテル／SAKURA Deeptech Shibuya |
| 規模 | 2,000名（完全招待制） |
| 主催 | TECHNIUM Global Conference 実行委員会 |
| 実行委員会の構成 | Beyond Next Ventures／電通／CoA Nexus／コランダム |
| 公式サイト | https://tcnm-gc.com/ |

社内の担当はオープンイノベーション部（[組織と部門](../resources/組織と部門.md)）。

## VCパートナー

VC を「VCパートナー」として招待し、参加チケットを無料で提供する。参画にあたって次を依頼する。

- 5件以上のシーズ・スタートアップの紹介
- イベントHPへのロゴ掲載（ロゴデータの提出）
- リリース発信時の SNS 告知への協力
- 内容に応じた登壇・ピッチへの協力

2026年の参画意思確認とロゴ提出の期限は5月15日だった。

VC 側の参加目的として案内しているのは、新規シーズやスタートアップのソーシング、国の重点領域のトレンド情報の獲得と政策ネットワークの拡充、投資先・支援先の事業連携や経営体制強化、ファンドのPR。

## 進行体制

準備は Slack のチャンネル単位で分かれている。2026年に作成されたものは次のとおり。

| チャンネル | 担当範囲 |
| --- | --- |
| `#technium-inquiry2026` | 問い合わせ |
| `#technium2026-会場オペレーション` | 会場運営 |
| `#prj-technium-pitch2026` | ピッチ |
| `#prj-technium-poster2026` | ポスター |
| `#prj-techniumセッション関係` | セッション |
| `#prj-technium-ガバメントサミット` | ガバメントサミット |
| `#prj-technium-学生パートナー` | 学生パートナー |
| `#prj-technium-産学連携night2-情報交換会` | 交流会（産学連携） |
| `#prj-technium-オープンイノベ交流会` | 交流会（オープンイノベーション） |
| `#prj-technium-交流会` | 交流会 |

このほか、2025年以前に作成され名称に `technium` を含むチャンネル（`#prj-technium_vc-partner`、`#prj-technium_academia-partner`、`#prj-technium-事業会社関係`、`#prj-technium-登壇者関係`、`#prj-technium-当日` など）がある。

チャンネル名は [Slack チャンネル運用](../resources/slack-チャンネル運用.md) の `prj-` に従う。
