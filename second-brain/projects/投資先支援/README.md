# 投資先支援

期限や完了条件がある、投資先支援案件を置く場所です。

## 📏 判断基準

投資先支援のうち、「いつか終わる」ものはここに置きます。採用支援、組織開発支援、資本政策の見直しなど、成果物や完了条件が決まっている案件が対象です。

継続的に担当している投資先との関係(定例のモニタリングなど、終わりが決まっていないもの)は [`areas/担当投資先/`](../../areas/担当投資先/README.md) に置きます。

投資先マスタ、財務資料、契約書などの構造化データは Notion・Google Drive が正本です。ここには全文を複製せず、要点と出典リンクだけを残します。

## 🗂️ ファイル名

`<企業名>-<支援テーマ>-<対象期間>.md` の形で置きます。

例: `anaut-組織開発支援-2026h1.md`

支援が完了したら [`archives/投資先支援/`](../../archives/README.md) に移します。
