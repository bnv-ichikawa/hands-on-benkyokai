# Projects

期限、成果物、完了条件がある作業を置く場所です。

## 置くもの

- 期限や完了条件がある仕事
- 記事、資料、レポートなどの成果物作成
- アプリや仕組みの開発
- イベント、旅行、学習計画などの準備
- 会議や日々の活動から生まれた具体的なアクション

## 📏 判断基準

「いつか役立つ情報」ではなく、「いま成果物に向けて動いている情報」はここに置きます。

小さいうちは `projects/<プロジェクト名>.md` として直下に1枚で置きます。判断記録、参考資料、議事録などが増えてきたら `projects/<プロジェクト名>/` に分け、入口の `README.md` に目的、完了条件、次のアクション、関連ノートをまとめます。

投資先支援のうち、期限や完了条件がある案件は [`projects/投資先支援/`](投資先支援/README.md) に置きます。

## 📝 ノートの型

社内プロジェクトのノートを書くときの型は [プロジェクトノートの型](../../docs/second-brain/references/project-note-template.md) にあります。
