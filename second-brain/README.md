# Second Brain Workspace Template

このリポジトリは、自分用の Second Brain を始めるためのワークスペーステンプレートです。

仕事や生活で得た知識、情報、判断、アイデア、作業記録を整理し、自分と AI が必要な文脈を取り戻して再利用できる状態を作ります。利用を始めるときは、このテンプレートを複製し、目的や管理対象を自分に合わせて調整してください。

## 管理するもの

- 進行中のプロジェクトに関する前提、判断、作業記録
- 継続的に維持したい仕事や生活の責任領域
- 記事、本、動画、調査などから得た再利用可能な知識
- 会議や打ち合わせの議事録、要点、決定事項、次のアクション
- 完了したプロジェクトや現在は使わない資料
- Second Brain やナレッジ管理の運用ルール

## 基本方針

情報を保存するだけでなく、あとから探し、理解し、AI と一緒に再利用できる形で残します。

| 考え方 | 使い方 |
| --- | --- |
| README | 人間と AI が最初に読む入口 |
| Markdown | ナレッジを人間にも AI にも読める形で残す |
| リンク | 関連するノートや資料をつなげる |
| PARA | ファイルや情報をどこに置くかを決める |
| AGENTS.md | 将来的に AI エージェント向けのルーティングルールとして使う |

## ディレクトリ

| パス | 役割 |
| --- | --- |
| `inbox/` | 未整理のメモや入力を一時的に置く |
| `projects/` | 期限、成果物、完了条件がある作業を置く |
| `areas/` | 継続的に維持・改善する責任領域を置く |
| `resources/` | 将来参照する知識や資料を置く |
| `archives/` | 完了、停止、または現在は使わない情報を置く |

このディレクトリには知識そのものだけを置きます。関連するものは、リポジトリのルートに分けてあります。

| パス | 役割 |
| --- | --- |
| `../.agents/skills/` | AI に作業方法を伝える Skill を置く |
| `../tools/` | 各自のPCで実行するプログラムを置く |
| `../docs/` | Second Brain とテンプレートの説明を置く |

## 関連ドキュメント

解説資料はリポジトリのルートの [`docs/`](../docs/README.md) にまとめています。

Second Brain は記憶を置き換えるものではありません。未来の自分や AI が過去の文脈を理解し、次の行動や成果物につなげるための外部記憶として育てていきます。
