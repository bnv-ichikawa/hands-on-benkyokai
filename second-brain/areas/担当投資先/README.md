# 担当投資先

継続的に担当している投資先との関係ログを置く場所です。

## 📏 判断基準

明確な完了日はないが、継続的にモニタリング・フォローしている投資先はここに置きます。

期限や完了条件がある個別の支援案件(採用支援プロジェクトなど)は [`projects/投資先支援/`](../../projects/投資先支援/README.md) に置きます。

投資先マスタ、財務資料、契約書などの構造化データは Notion・Google Drive が正本です。ここには全文を複製せず、支援の中での自分の判断や気づきなど、正本に載らない情報だけを残します。frontmatter の `source_notes` に、対応する Notion・Drive・Slack への参照リンクを残します。

## 🗂️ ファイル名

`<企業名>.md` の形で置きます。

担当を外れた投資先は [`archives/`](../../archives/README.md) に移します。
