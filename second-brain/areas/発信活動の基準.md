# 発信活動の基準

対外的な発信で守る基準。正本は Notion「発信活動におけるガイドライン（日本）」で、判断に迷ったら正本に戻る。

## 適用範囲

当社におけるすべての発信活動。公式SNS、登壇、メディア取材、オウンドメディア、Webサイト、会社案内資料、採用・求人ページ、営業資料など。

## 基本姿勢

研究者・起業家の挑戦に伴走するパートナーとして、**謙虚さ・熱意・リスペクト**を発信の基準とする。

- 自分たちを主役にせず、黒子としての振る舞いをする（主語は挑戦者）
- 豊富な経験と実績で語りつつ、驕りを感じさせない誠実さを保つ
- 不確実性を前提に、断定・誇張・過度な表現を避け、慎重に言葉を選ぶ
- 批評や評価ではなく、可能性と文脈を伝える
- 事象やトレンドを俯瞰的にとらえ、専門家として深さのある発言を心がける

## 場面別の扱い

| 場面 | 扱い |
| --- | --- |
| メディア取材 | その場で確約せず一旦社内に持ち帰り、広報と相談のうえ回答する。編集権限はメディア側にある前提で臨む |
| SNS | 未公表・推測できる情報の発信は避け、必ず投稿前にチェックする |
| 登壇・資料作成 | 会社の代表として見られていることを意識する |
| 会社を説明する | 経営理念、ミッション、公式会社説明文（全文255文字／短縮146文字）は正本の表現をそのまま使う |
| 部門・プログラムを説明する | 正本の公式説明文を使う（[組織と部門](../resources/組織と部門.md)） |

## トラブルが起きたとき

発信した情報や行動が社会的な誤解・批判・炎上につながる可能性が生じた場合、「早く説明すること」よりも「誤りを拡大させないこと」を重視する。出資先やLPなど、ステークホルダーとの信頼関係を常に最優先する。

基本原則:

- 個人判断で対応しない
- 即時の発信・反論を行わない
- 事実確認と社内共有を最優先する
- 当事者・出資先・関係者・所属組織の尊厳を守る

初動は **事実確認 → 方針決定 → 必要最小限の対応** の順序を守る。

## 維持のしかた

- 正本は広報（ファンド・コーポレート部）が管理する
- ロゴ規定、フォント規定・カラーコード、公式スライドマスターは正本のライブラリから取得する
- ロゴを使うときは社内申請が必要
