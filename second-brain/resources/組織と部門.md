# 組織と部門

各部門の定義と主な活動内容をまとめる。正本は Notion「公式説明文（プログラム・部署）」で、ブランドガイドライン配下にある対外発信用の承認済み説明文。

## 部門一覧

| 部門 | 概要 | 主な活動内容 |
| --- | --- | --- |
| 国内投資部 | 日本国内のシード・アーリー期ディープテックスタートアップへの投資を担う部門 | 新規出資、出資先支援（人材・事業開発・海外展開・広報など） |
| HR戦略部 | 当社の投資に付随する組織・人材課題の解決を担う部門 | 創業経営人材の発掘・育成、出資先経営幹部人材の採用支援、ILP等の人材関連プログラムの運営、起業家スコア等の企画・運営 |
| オープンイノベーション部 | ディープテックスタートアップと大企業との連携を促進する部門 | 大企業の意思決定層とのリレーション構築、TECHNIUM Global Conference の企画・運営 |
| 科学未来ラボ | 研究環境の改善と研究人材の活躍促進に取り組む部門 | 博士課程進学者向けリーダーシップ教育プログラムの実施、日本科学未来財団の運営を通じた学生・研究者への資金提供活動 |
| ファンド・コーポレート部 | ファンド運営とコーポレート機能を担い、当社事業の持続的成長を支える部門 | ファンド管理、経理、法務、人事、総務、広報などのコーポレート機能全般 |
| インド子会社 | インドにおけるディープテックを中心としたスタートアップへの投資と日印連携を推進するチーム | インドのスタートアップへの投資、日本企業のインド進出支援やビジネスマッチングを通じた日印連携の推進 |

対外的な説明には、上の「概要」の表現を使う。
