# Slack チャンネル運用

社内 Slack のチャンネル命名ルールと投稿先の選び方をまとめる。

## プレフィックス

チャンネル名の先頭に、用途を表すプレフィックスを付ける。

| プレフィックス | 用途 | 命名の単位 |
| --- | --- | --- |
| `inv-` | 投資検討先・投資先ごとのやりとり | 1社1チャンネル |
| `fund-` | ファンド運営に関する業務 | 業務機能ごと |
| `adm-` | 管理部門への申請・依頼 | 申請の種類ごと |
| `lab-` | 科学未来ラボの運営 | 業務機能ごと |
| `prj-` | 期限のあるプロジェクト | 案件ごと |
| `group-` | 継続的なテーマ別・チーム別の議論 | テーマごと |
| `news-` | 領域別のニュース・情報共有 | 領域ごと |
| `pr-` | 広報 | 業務機能ごと |
| `dd-` | デューデリジェンス | 案件ごと |
| `collabo_` | 社外・グループ会社との協業 | 相手先ごと |
| `old_` | 廃止済みチャンネル | 旧チャンネル名の先頭に付ける |

## 命名ルール

- プレフィックスと本体はハイフンで区切る
- 本体は小文字の英数字とハイフンで構成する。日本語を使うチャンネルもある
- 対象を絞り込むときは、ハイフンでつないで階層を表す（`prj-technium-poster2026`、`fund-india-management`、`adm-india-contract-investment`）
- 部門・機能全体の連絡先は `<プレフィックス>-general`（`inv-general`、`fund-general`、`adm-general`、`lab-general`、`pr-general`、`news-general`）
- 廃止したチャンネルは削除せず、先頭に `old_` を付けてリネームする

## 投稿先の選び方

| 内容 | 投稿先 |
| --- | --- |
| 特定の投資先に関する話 | `inv-<企業名>` |
| 管理部門への申請・依頼 | `adm-<申請名>` |
| 期限のある案件の進行 | `prj-<案件名>` |
| 継続的なテーマの議論 | `group-<テーマ>` |
| ニュース・記事の共有 | `news-<領域>` |
| 部門全体への連絡 | `<プレフィックス>-general` |
| 上記に当てはまらない全社連絡 | `#general` |

## 表記のゆれ

上のルールと異なる表記のチャンネルが存在する。

- 区切り文字にアンダースコアを使う: `news_agrifood`、`news_ipo`、`group_equity_holders`、`prj-technium_vc-partner`、`collabo_bnv-es_general`
- プレフィックスを付けない: `#general`、`#news`
- プレフィックスを末尾に置く: `portflio-news`
- 個人名を使う: `hashizume_news`、`news-ito`
