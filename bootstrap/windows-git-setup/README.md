# windows-git-setup

`bootstrap/windows-git-setup/` は、Windows PCにGitを導入・初期設定し、`hands-on-benkyokai`をcloneするセットアップ方法とSkillを置く場所です。

このSkillは、WinGetの確認・準備、Git for Windowsの導入とPATHの反映、リポジトリのclone、Git identityの設定までを行います。

## 🗂️ ディレクトリ構成

```text
windows-git-setup/
├── README.md    このディレクトリの案内
├── SKILL.md     Codexが実行するセットアップ手順
└── agents/      Skillの表示設定
```

## 🚀 基本的な使い方

[`SKILL.md`](SKILL.md)の内容を、そのままCodexに渡してください。CodexはSkillを作成するのではなく、書かれている手順に従ってGitの導入からリポジトリのcloneまでを実行します。
